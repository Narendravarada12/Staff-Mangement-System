# 📖 2. Abstract

The **Staff Management System** is a web-based application designed to automate and simplify the management of staff information within an organization.

The system provides a centralized platform for managing:

* Staff records
* Departments
* Attendance
* Leave
* Salary
* Authentication
* Reports

The project is developed by following Software Project Management principles such as project planning, requirement analysis, feasibility analysis, Work Breakdown Structure (WBS), scheduling, resource management, risk management, cost estimation, quality management, testing, deployment, monitoring, and project closure.

The actual software implementation is performed using **Python, Django, HTML, CSS, JavaScript, and MySQL**.

---

# 🎯 3. Problem Statement

Many organizations manage staff information using paper records, spreadsheets, or separate systems.

This can result in:

* Duplicate records
* Data loss
* Manual paperwork
* Difficulty searching employee information
* Attendance management problems
* Leave tracking problems
* Salary management issues
* Difficulty generating reports
* Poor data organization
* Security problems

Therefore, a centralized Staff Management System is required to improve the efficiency, accuracy, and security of staff management.

---

# 💡 4. Proposed Solution

The proposed system provides a centralized web application where authorized users can manage staff-related information.

The administrator can:

* Add employees
* View employees
* Update employees
* Delete employees
* Search employees
* Manage departments
* Manage attendance
* Manage leave
* Manage salary information
* Generate reports
* Manage users

The system reduces manual work and provides faster access to staff information.

# 👤 37. Create Staff Model

Open:

```text
staff/models.py
```

Add:

```python
from django.db import models


class Department(models.Model):
    name = models.CharField(max_length=100)
    description = models.TextField(blank=True)

    def __str__(self):
        return self.name


class Staff(models.Model):
    employee_id = models.CharField(
        max_length=20,
        unique=True
    )

    name = models.CharField(max_length=100)

    email = models.EmailField(unique=True)

    phone = models.CharField(max_length=15)

    address = models.TextField()

    designation = models.CharField(max_length=100)

    department = models.ForeignKey(
        Department,
        on_delete=models.CASCADE
    )

    joining_date = models.DateField()

    salary = models.DecimalField(
        max_digits=10,
        decimal_places=2
    )

    status = models.CharField(
        max_length=20,
        choices=[
            ('Active', 'Active'),
            ('Inactive', 'Inactive'),
        ],
        default='Active'
    )

    def __str__(self):
        return self.name
```

# ⏰ 38. Attendance Model

```python
class Attendance(models.Model):

    staff = models.ForeignKey(
        Staff,
        on_delete=models.CASCADE
    )

    date = models.DateField()

    status = models.CharField(
        max_length=20,
        choices=[
            ('Present', 'Present'),
            ('Absent', 'Absent'),
            ('Leave', 'Leave'),
        ]
    )

    def __str__(self):
        return f"{self.staff.name} - {self.date}"
```

```python
class Leave(models.Model):

    staff = models.ForeignKey(
        Staff,
        on_delete=models.CASCADE
    )

    start_date = models.DateField()

    end_date = models.DateField()

    reason = models.TextField()

    status = models.CharField(
        max_length=20,
        choices=[
            ('Pending', 'Pending'),
            ('Approved', 'Approved'),
            ('Rejected', 'Rejected'),
        ],
        default='Pending'
    )

    def __str__(self):
        return self.staff.name
```

# ➕ 45. Add Staff

```python
def add_staff(request):

    if request.method == 'POST':

        Staff.objects.create(

            employee_id=request.POST['employee_id'],

            name=request.POST['name'],

            email=request.POST['email'],

            phone=request.POST['phone'],

            address=request.POST['address'],

            designation=request.POST['designation'],

            department_id=request.POST['department'],

            joining_date=request.POST['joining_date'],

            salary=request.POST['salary'],
        )

        return redirect('staff_list')

    departments = Department.objects.all()

    return render(
        request,
        'staff/add_staff.html',
        {'departments': departments}
    )
```
